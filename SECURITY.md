# Security

forkrail runs in your own AWS account, with the rights it needs to deploy and serve your apps, so
a security problem in it can reach that account. Please tell us about one privately.

## Reporting a problem

Don't open a public issue. Use GitHub's private reporting instead: this repository's Security tab,
then **Report a vulnerability**
([direct link](https://github.com/soorower/forkrail-cli/security/advisories/new)). This covers the
dashboard ([soorower/forkrail-dashboard](https://github.com/soorower/forkrail-dashboard)) too.

Please include what's affected (the CLI, a router, a function, the dashboard), how to reproduce
it, and the version (`forkrail --version`). We'll reply in the report, and credit you in the fix's
advisory if you'd like.

## Versions

Fixes go into a new release. Install the newest CLI with the install command in the
[README](README.md).
